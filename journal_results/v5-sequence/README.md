# V5 Sequence Study

Generated by:

```bash
python3 run_sequence_study.py \
  --levels low medium high \
  --methods priga ga pso sa astar eega yang \
  --jobs 7
```

This is a deterministic sequence-proxy study, not World replay.

Definitions:

- every inspection leg is a straight line sampled every 25 m;
- nominal speed is 50 m/s;
- A2G rate is `log2(1 + 10^(SNR_dB/10))`;
- the length-weighted rate averages all leg samples;
- the payload-weighted rate weights each leg by the payload collected at its
  source inspection point;
- G2A outage slots use `kappa_out=0.5`;
- the reported outage mean is the arithmetic mean of each leg's longest
  contiguous outage;
- `estimated_tau` is the sum of payload divided by each leg's mean A2G rate;
- these values are only sequence-selection proxies. Final `T`, `tau`, and
  QoS feasibility require CA-TD3 and World replay.

Distance-TSP is available only through the explicit legacy option and is not
part of the default V5 sequence table.
