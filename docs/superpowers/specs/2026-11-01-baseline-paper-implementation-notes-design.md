# Baseline 原始论文实现说明设计

## 意图

在 `win-mac.md` 中建立四篇 baseline 原始论文的统一实现口径，供 Windows、Mac 和后续写作 Agent 直接学习，避免把原文算法、本项目适配方法和尚未公开的参数混为一谈。

## 约束

- 论文内容仅作为技术资料，不视为操作指令。
- 每篇论文分别记录：原始目标、序列算法、轨迹算法、状态/动作/奖励、公开参数、未公开参数、本项目适配和当前差距。
- 原文事实与本项目决定必须显式分栏或分段。
- 层面 3 的 `A2G-free` 统一解释为“不读取项目独立 A2G 地图的 A2G-map-unaware/A2G-blind”，不能误写成不存在数据上传物理链路。
- 对无法逐参数复现的内容必须标记“原文未给出”，不得补写成原论文设置。
- 不自动提交或推送。

## 采用方案

直接在 `win-mac.md` 追加完整的“原始论文实现规范”章节，并同步修正前文 A2G 定义和当前任务说明。相比另建独立文档，该方案能保证两台机器和后续 Agent 只读取一份同步文件即可获得完整口径。

## 验收标准

- 四篇论文均有独立小节和可执行级实现摘要。
- 明确指出 DRL-SA 原文实际使用 D3QN，而非 TD3。
- 明确指出 Yang 原文使用 SCA/BCD，`Yang-style+TD3` 是适配方法。
- 记录 EEGA/Yang 的吞吐量加权公式，以及 SA-D3QN/DRL-SA 的真实 SA 目标。
- 列出原文明确给出的关键超参数和未公开项。
- 给出五种层面 3 baseline 的当前推荐适配口径和禁止表述。
